📷 Image Classification Web App (CIFAR-10)
🚀 Overview

This project is an end-to-end Image Classification system built using Convolutional Neural Networks (CNN). It classifies images into 10 categories from the CIFAR-10 dataset and provides real-time predictions through a web interface.

🧠 Features
Image classification using CNN
Trained on CIFAR-10 dataset (10 classes)
Real-time prediction via web app
Image upload functionality
Clean and simple UI
Lightweight and deployable
🏷️ Classes

The model predicts the following categories:

Airplane
Automobile
Bird
Cat
Deer
Dog
Frog
Horse
Ship
Truck

🛠️ Tech Stack
Python
TensorFlow / Keras
Flask
NumPy
Pillow (PIL)
